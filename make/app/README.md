# Checkout Page

Use Checkout Page in your Make scenarios. Start a scenario when something happens to a payment, booking, ticket, subscription, submission or customer. Search for and get your payments, bookings, customers, checkout pages, events, forms and more. Create a booking, create a coupon or update a customer. For anything else, use Make an API call.

## Connect

1. In the Checkout Page dashboard, go to Settings, Developers, API keys and create an API key.
2. In Make, create a Checkout Page connection and paste the API key into it.

## Webhooks

Each trigger adds a webhook to your Checkout Page account, named after your scenario, for example "Make: New bookings to Google Sheets". An account can have up to 10 webhooks, so remove the ones you no longer use under Settings, Developers, Webhooks.

Make ignores the test delivery you send from the Checkout Page dashboard.
